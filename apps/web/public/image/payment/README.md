# Payment Icons

Thư mục này chứa các icon cho phương thức thanh toán.

## Các file cần thiết:

1. **momo.png** - Icon ví MoMo (200x200px)
2. **vnpay.png** - Icon VNPay (200x200px)
3. **bank.png** - Icon chuyển khoản ngân hàng (200x200px)
4. **cod.png** - Icon thanh toán khi nhận hàng (200x200px)

## Lưu ý:
- Kích thước khuyến nghị: 200x200px hoặc 400x400px
- Định dạng: PNG với nền trong suốt
- Nếu không có icon, hệ thống sẽ sử dụng ảnh mặc định từ `/image/post/default.jpg`

## Nguồn tải icon:
- Logo chính thức từ website của các nhà cung cấp
- Icon miễn phí từ Flaticon, Icons8
- Tự thiết kế theo brand guideline
